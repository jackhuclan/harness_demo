# 技能 · 数据统计

## 所属 Agent
生产数据分析（pda）

## 触发示例
- 帮我看下这批 LOT 的统计结果
- LOT-2207 的 X/Y 3σ 是多少？
- 这批片有没有超规告警？

## 执行工具
`ovl_statistics`（无入参）

## 输出内容
- X 方向 3σ / Y 方向 3σ
- 片内最大 3σ（iPW 指标）
- TIS 3σ（套刻对准指标）
- 超规告警（红色标记超出 spec 的项）

## 示例输出
```
## 📊 OVL 统计报告（LOT-2207）

| 指标 | 实测 | Spec | 判定 |
|---|---|---|---|
| X 3σ | 0.18 nm | ≤ 0.30 | ✅ |
| Y 3σ | 0.21 nm | ≤ 0.30 | ✅ |
| iPW max 3σ | 0.25 nm | ≤ 0.35 | ✅ |
| TIS 3σ | 0.12 nm | ≤ 0.20 | ✅ |
```
