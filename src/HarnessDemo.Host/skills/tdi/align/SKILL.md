# 技能 · 精对准失败诊断

## 所属 Agent
机台诊断修复（tdi）

## 触发示例
- 看下当前机台为什么报错

## 执行工具
`ovl_diagnose`（入参：`{error:"精对准失败"}`）

## 输出内容
识别到机台当前处于报错状态，正在自动调取报错上下文与量测日志…

### 1. 报错 · 精对准失败（Foup1 · slot2）
量测 Foup1 slot2 时精对准（Fine Alignment）失败，流程中断。

### 2. 诊断 · 根因定位
该 wafer 的精对准图形与处方模板差异较大，导致图形匹配（matching）失败。

### 3. 处置 · 自动留存备用模板
已自动将该 wafer 精对准图案存入备用模板库（backup template），供重匹配使用。
