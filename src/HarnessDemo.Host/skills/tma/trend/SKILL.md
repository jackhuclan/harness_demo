# 技能 · 近两月机台性能趋势

## 所属 Agent
机台监测分析（tma）

## 触发示例
- 看下近两个月机台的性能情况

## 执行工具
`tool_trend`（入参：`{weeks:8}`）

## 输出内容
已拉取近 8 周（W1-W8）机台监测分析记录，趋势如下：

### 趋势图（nm，重复性 spec 0.25）
- X 轴：W1 ~ W8
- 蓝线（重复性 3σ）：从 0.18 缓慢升至 0.24 nm，W8 逼近 spec
- 橙线（TIS）：在 0.10~0.16 nm 间平稳波动
- 红色虚线：spec = 0.25 nm

### 建议
重复性 (3σ) 末周升至 0.24 nm，已逼近 spec 上限（0.25 nm），虽仍在控但呈缓慢上行趋势：
- 建议自查 TIS / calibration 状态
- 建议安排机台 PM
- TIS 整体平稳（0.10–0.16 nm）
- 可结合「运行机台监测分析」做定点复核
