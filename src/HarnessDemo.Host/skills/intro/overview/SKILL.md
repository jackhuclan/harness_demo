## 输出内容
### 👋 欢迎使用 OVL Agent Harness

本系统是基于 Agent Harness 架构的 OVL（Overlay 套刻）智能制造助手，覆盖 **5 个智能体**，共 **13 项技能**：

### 📦 处方管理
负责处方全生命周期：
- **处方建立及调试**：13 步建方流程，关键步骤暂停等待确认
- **处方分析**：基本信息 / 运行统计 / 失败归类 / 优化建议

### 📊 生产数据分析
对生产片 OVL 数据做完整分析：
- **数据统计**：X/Y 3σ、iPW、TIS 3σ、超规告警
- **异常分析**：失败定位 + 根因研判
- **性能分解 Budget**：Raw/W1F1/W3F3/CPE/Residual 贡献占比
- **归因分析**：field-to-field 残差 + R² 证据
- **决策建议**：模型升级 / 采样 / 工艺改进方向
- **多技能串联**：一键跑完整分析链路

### 🔧 机台监测分析
监控机台本身状态：
- **运行机台性能检测**：重复性 / TIS / MAM，超标时主动预测原因
- **近两月性能趋势**：8 周走势 + spec 逼近判定
- **机台硬件状态分析**：光源衰减曲线 + 剩余寿命预估

### 🩺 机台诊断修复
报错自动诊断与处置：
- **精对准失败**：图形匹配失败根因 + 备用模板留存
- **粗聚焦失败**：Focus Travel 参数调整建议

### 🚀 快速开始
直接在输入框描述你想做的事，例如：
- 「分析下 ProductA_M1M2_Layer 这个处方」
- 「帮我看下 LOT-2207 的统计结果」

- 「看下当前机台为什么报错」
- 「帮我给 Foup2 的 slot5 建个 OVL 处方」
